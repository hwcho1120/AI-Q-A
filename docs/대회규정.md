# 대회 규정 요약 (운영진 안내문 기준)

## 배점 (기업지표 20점, 내부 100점 환산)
- 근거 정확도 40: 비공개 테스트셋 정량 평가
- 신뢰도 확보 20: 근거 없을 때 '확인 불가', 원문 링크·시행일 제공
- 답변 품질 20: 일반인이 이해할 말로 정확히 (심사위원)
- 서비스 시연 20: 실제로 쓸 만한 서비스인지 (발표)

## 엔진 vs 서비스
- 엔진(채점용 API): 6종 전체에 근거를 대며 답해야 함. 테스트셋 비공개, 6종 안에서만 출제.
- 서비스(시연): 사용자는 팀이 자유롭게 정함 (범위: 서울시 조례를 일상 언어로 묻는 시민·공무원). 화면·질문 유도·안내·시나리오를 그 사용자에 맞춰 설계. 엔진은 어떤 주제든 답해야 함.

## 세부 규칙
- 대상: 서울특별시 조례 6종, 2026-10-01 시행본 기준. 자치구 조례 인용 시 오답.
- 입출력: answer, citation, source_url, effective_date 4필드 JSON. 필드명 틀리면 오답.
- 인용: 조+항 만점, 조만 부분 점수, 인용 없으면 답이 맞아도 오답.
- 근거 없는 질문: {"answer": "확인 불가", "citation": []} 만 정답.
- 채점: 최종 제출 후 Upstage 내부 테스트셋 정량 평가 + 발표·심사 종합.

## 0점 조건
- 문항당 90초 초과 / 오류 응답(서버 오류, JSON 깨짐) / 채점 시점 서버 꺼짐(전 문항 0점)
- 모르면 '확인 불가'가 0점보다 낫다.

## 최종 제출물
1. 채점용 API 주소 (POST, 채점 끝날 때까지 켜져 있어야 함)
2. 발표자료: 사용자와 문제 / 시연(녹화 영상) / 시스템 구성(수집·파싱·검색·생성·검증 단계별 Upstage 모델) / 베이스라인 대비 개선 / 한계점
3. GitHub public 저장소, README에 실행 방법, .env 업로드 금지

## 모델 규칙
- 개발 중 AI 도구는 자유. 최종 서비스 모델은 Upstage 제공 모델만.
- 크레딧 인당 약 $100. 수상 후보는 소스코드 재현성 검증.

## 평가셋 4유형
단순 조회 / 조건 판단(네·아니요) / 여러 조항 결합(원칙+예외) / 근거 없음(함정 → 확인 불가)
